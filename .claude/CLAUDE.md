# BatonE2E 作業ルール（毎回最初に読む）

## 再開手順（作業が途中で中断→再試行になることがある）
Claudeの利用上限(5時間)などで作業が途中中断し、再開時に二重実装や未コミットの混在が起きた実績がある。必ず次を行う。
1. `git status --short` / `git stash list` / `git log --oneline | head` を最初に実行。作業ツリーが綺麗だと仮定しない。
2. `PROJECT.md` の「現在の状態」「作業メモ」を読む。
3. 覚えのない変更があれば、編集前に退避（`git stash` や patch 保存）し、内容を確認して整理してから進める。同じ機能を二重に書かない（既存実装を先に検索）。
4. 小さい単位で頻繁にコミット＆push。着手前に「いま何をやるか」を PROJECT.md の作業メモに1行書く。完了したら消す。
5. 実機テストの結果は利用者がログで報告する。ビルド・テストは GitHub Actions のみ（ローカルにdotnetは無い）。

## 方針
- 仕様の正は `PROJECT.md`（元仕様は `docs/BatonE2E.txt`）。コードは `src/` のみ、リポジトリ直下は最小限。
- 文言は `Lang/ja.ini` に外出し。非商用・再配布禁止ライセンス。
- docs/.md/.txt のみの変更ではビルドしない（paths-ignore）。
- コミットメッセージは日本語。
